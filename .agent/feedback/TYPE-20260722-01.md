## Lesson

External JSON should stay `unknown` until a guard validates every field the
consumer relies on. The guard keeps provider failures deterministic when a
successful HTTP response has an invalid payload shape.

## Follow-up

Audit other provider adapters for unchecked JSON response assertions. No
additional product follow-up is required for this focused change.
