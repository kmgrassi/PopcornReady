## Lessons

An embedded NUL inside a valid TypeScript string caused ordinary repository
search to treat a live orchestration file as binary and undercount five RPC
calls. The boundary validator now parses every source file from bytes, rejects
future NULs, and the source uses the escaped `\u0000` spelling to preserve its
hash delimiter exactly.

Mocked transaction tests are useful only when they assert the exact same-client
query order and every failure branch. The local integration adds the missing
observable proof: DDL created before a forced error is absent when checked from
a second connection.

## Follow-up

Provision a dedicated least-privilege API database role, then migrate one
existing service-role workflow RPC family per PR and shrink the allowlist with
each cutover.
