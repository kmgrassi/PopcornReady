## Lesson

Large browser suites are easiest to maintain when split by user-facing behavior:
project context/recovery, proposal review lifecycle, and generation progress.
Shared route fulfillment belongs in a small fixture module so the suites retain
the same setup without duplicating mock contracts.

## Follow-up

When extracting E2E cases, export every helper used by moved route handlers and
run the complete file set immediately; targeted individual cases can miss an
unbound shared helper.
