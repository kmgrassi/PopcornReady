## Lessons

The confirmation RPC incident and this generation failure were separate
boundaries. Browser smoke was valuable because it proved the direct-Postgres
confirmation worked before exposing the next stale caller.

The story-spine drop migration shipped before this independently owned
orchestrator context reader was repointed. A unit test over injected snapshot
rows did not catch that drift because it never invoked the production reader.
Persistence-boundary tests must call the real reader methods and assert their
exact table names as well as their returned projection.

For creator-direct standalone assets, an empty story spine is valid context.

tools without fabricating a storyboard, beat, panel, or compatibility row.
