## Lesson

A root hierarchy cannot be rolled out by replacing only its prompt: the same
fence must select its registry, graph context, and the specialist roles the
durable worker can execute. Otherwise a root can dispatch an Audio assignment
that no worker will claim.

Fresh graph projection plus root action history keeps the root aware of
immutable assets, selections, gates, pins, costs, and its own delegated report
boundaries without treating creator-direct pool history as approved production
truth. The temporary hierarchy flag is deployment-stable while those durable
runs drain.

## Follow-up

PR 17 should extend the root projection with the creator-visible hierarchical
run/report view; PR 18 owns the default-on rollout and soak criteria.

## PR review follow-up

Delegated output requirements are a completion contract, not an inferred media
stage. A root assignment must name its bounded Visuals terminal kinds so an
anchor/storyboard request can complete at the storyboard boundary rather than
being forced into a clip. Root context may include completed reports only when
their durable child run is linked to that root with the creative-director
origin; creator-direct reports remain a separate creator-facing history.
