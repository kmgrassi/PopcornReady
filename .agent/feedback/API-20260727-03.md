## Lesson

When a new capability must join a typed catalog that many flat production
surfaces iterate, add the entry with an explicit surface marker and split the
name list (PRODUCTION vs DISPATCH) in the same commit — every consumer then
states which vocabulary it means, and "nothing user-visible changes" becomes
an assertable property instead of a hope. Deriving the child-run id from the
idempotency key (sha256 → uuid) let the database's primary keys serialize
concurrent duplicate dispatches without any advisory locking: the loser's
transaction rolls back whole, and one retry lands in the replay branch.
