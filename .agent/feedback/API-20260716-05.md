## What helped

Production ledger inspection established that current spend was image-only and
that `model_call_costs` already had the token fields needed for text calls. The
two existing LLM adapter layers made the correct interception point clear, and
the independent review identified the need to account for every structured
output retry before parsing its result. PR review later caught a second
project-owned LLM call: display-name generation after asset generation, which
must receive the same project/run/action observer scope as preflight.

## Friction and improvement

The current ledger cannot store separate cache-token buckets, so the estimate
uses them while raw persisted fields remain provider input/output totals. A
future reconciliation change should add typed cache columns or a versioned
usage payload before relying on this ledger for invoice-grade cache analysis.
This change deliberately provides post-hoc visibility rather than pre-request
LLM budget reservation or credit settlement. Global calls without a known
project owner (including embeddings and naming) should remain unledgered until
their ownership boundary is explicit rather than borrowing a nearby project ID.
