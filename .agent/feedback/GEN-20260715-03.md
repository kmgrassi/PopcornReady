## What helped

The production run supplied a concrete mismatch between the New Project promise
of an automatic rough cut and the API's hidden storyboard stop. Independent
research separated that entrypoint bug from the storyboard/keyframe data
handoff, and the local Supabase test verified the full relational and storage
path without spending provider credits.

## Friction and improvement

The first implementation validated completeness only after creating a
storyboard, but creation also published the mutable project pointer. Future
immutable-stage builders should create unpublished attempts and expose a
separate publication operation from the start. Review also caught that checking
only asset kind, role, and readiness is insufficient: beat and plan provenance
are part of the handoff contract. Candidate recovery queries must stay bounded
because failed immutable attempts intentionally accumulate.

The full API suite currently includes three unrelated baseline failures: two
guest-retention tests reference migrations absent from this checkout, and the
discover UUID-shape assertion fails. Targeted generation tests, typecheck, the
real local-database integration, and browser progress regressions remain the
authoritative validation for this change.

PR review exposed one final error-taxonomy boundary: a deleted tile is expected
stale graph state, not an infrastructure outage. Candidate loaders should turn
only typed `not_found` into a missing-asset handoff issue and rethrow every other
read failure.
