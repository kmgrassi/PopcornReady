## Lesson

Budget limits must be admitted and released/settled through durable operation
identities. A read-then-write cost check is unsafe when independent domain runs
can fan out concurrently or workers can crash between provider completion and
accounting.

## Follow-up

Run the local-Supabase integration suite for reservation, confirmation, and
recovery RPCs before enabling a domain profile against billable providers.
