## Lesson

The repository already had most of the vocabulary for safe production testing,
including sandbox purposes, TTLs, deployment metadata, local-Supabase browser
coverage, and a fixture corpus. The main gap was not another checklist; it was a
release-coherent remote runner and a least-privilege lifecycle connecting those
pieces without giving the browser trusted credentials.

Independent review materially improved the ordering by making release identity,
the control-plane threat model, complete cleanup, cost isolation, and evidence
redaction prerequisites for production mutation rather than later hardening.

PR review exposed that lifecycle evidence cannot live in a row whose workspace
foreign key cascades on cleanup. Durable test-run evidence and ephemeral sandbox
ownership are separate records. It also confirmed that public-sharing canaries
must stay inside the internal-test cleanup boundary rather than granting deletion
authority over normal user workspaces.

The PR's browser failure also showed that compatibility helpers can conceal UI
contract drift. A helper that conditionally supported both an inline field and
an obsolete modal raced a reload, chose the wrong branch, and turned one
behavior test into three browser-specific outcomes. Browser actions should wait
for the current control contract, synchronize the exact API transition, and
then assert the resulting visible state.
