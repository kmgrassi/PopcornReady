## Lesson

The keyframe path preserved caller ordering but flattened character anchors,
scene anchors, and storyboard sketches into one generic path array. Ideogram's
adapter then labeled every path as a character reference even though its v3
generate endpoint permits at most one. Enforcing the hard provider limit at the
adapter prevents every caller—including workspace-default generation—from
submitting an invalid payload. Inspecting `FormData.getAll()` and the retained
Blob bytes made the regression test prove observable request behavior rather
than only a helper call.

## Follow-up

Add a typed reference contract that distinguishes character, style/scene, and
structural composition inputs, then record effective provider inputs separately
from requested graph provenance. That larger design can evaluate Ideogram remix
or provider routing without guessing roles or changing keyframe semantics in a
production hotfix.
