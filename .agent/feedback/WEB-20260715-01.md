## What helped

The production attempt supplied a concrete failure shape: long provider work,
failed clip prerequisites, storyboard recovery, and a terminal run without a
video. Independent research and plan reviews turned that evidence into explicit
projection invariants before UI work began.

## Friction and improvement

Run summaries and run details have intentionally different evidence. Workspace
summaries cannot infer provider waits or recovery without joining action data,
so they should stay generic instead of copying detail-level claims. Future
loading-state plans should distinguish lifecycle activity timestamps from true
worker heartbeats and require negative tests for missing/non-ready artifacts.

PR review reinforced the same boundary: when a workspace summary lacks export
evidence, label the lifecycle (`Succeeded`) without claiming either “Video
ready” or “Run ended without output.” Also verify that inline layout styles do
not override reduced-motion-safe indeterminate CSS.
