## Lesson

Stopping after a completed storyboard needs an actionable review projection,
not a generic terminal success. The same durable reopen path must support both
approval and requested changes, while retaining the stage identity that UI
surfaces and dashboard summaries use.

## Follow-up

Implement scene-level visual anchors as first-class generated assets, require
them before beat storyboard generation, and pass the selected anchors as real
provider references. The current scene wireframe remains an optional,
disposable review aid.
