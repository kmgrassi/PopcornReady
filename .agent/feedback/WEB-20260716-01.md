## Lesson

The shared `MediaViewer` already provided full-screen image behavior, keyboard dismissal, and responsive layout; the missing piece was making the Inspiration poster supply a `MediaViewerItem` instead of rendering as a standalone image.

## Follow-up

No universal image-viewer policy was inferred. Other image surfaces should adopt the shared viewer when their interaction model calls for inspection rather than navigation or an object-scoped change request.
