## Lesson

Migration filenames need a cheap repository-wide uniqueness invariant.
`--include-all` drains out-of-order migrations, but two files with the same
version collide in `supabase_migrations.schema_migrations` and can freeze every
later production schema change while the API continues deploying. A collision
repair must also replay both idempotent DDL branches under fresh versions;
different environments may have recorded opposite sides of the collision.

## Follow-up

Monitor the post-merge migration workflow through all queued migrations, then
verify `orchestrator_runs.root_execution_profile` and production orchestrator
run creation before declaring the incident resolved.
