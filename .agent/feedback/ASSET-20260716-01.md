## Lesson

For tileable terrain textures, an opaque edge-to-edge bitmap is compatible with
runtime hex clipping; a transparent background is not. Documenting that boundary
alongside the assets prevents callers from treating a source texture as a
pre-clipped map tile.

## Follow-up

When an Ideogram API key is supplied to the worktree, regenerate through the
configured provider and preserve the exact opposite-edge continuity check before
replacing this set.
