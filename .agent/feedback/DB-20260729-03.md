## Lesson

A valid migration can still install a function that fails only when executed:
the fixed `public` search path hid pgcrypto's `extensions.digest`. Forward
repairs must copy the newest function body, qualify extension dependencies, and
execute the repaired path against local Postgres instead of relying only on
migration-text assertions.
