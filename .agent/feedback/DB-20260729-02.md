## Lesson

Fixing the first statement that blocks a migration queue is not enough when a
historical filename collision covered multiple paired migrations. Production
can have a valid recorded version while missing the other migration's enum,
table, function, trigger, and policies. Forward repair needs metadata audits and
fresh replay versions at the correct transaction boundaries.
