## Lessons

The PR 2 child-budget contract distinguishes the parent work dispatch from
true provider primitives. A rerun adapter must dispatch a bounded domain child
and must not invoke providers, reserve provider budget, or mark the parent
dispatch applied itself.

The child task carries the exact proposal, approval, execution reservation,
pins, output bindings, executor id, work item id, and callback generation.
Canonical child tools create the provider actions/jobs. Shared domain
finalization derives those primitive action ids and settled reservation keys
before recording the fenced lifecycle callback.

Late video completion is safe because the adapter never writes selections and
the callback recorder validates the exact generation, reservation, work item,
executor, child run, report, primitives, and bindings. A stale callback leaves
immutable assets pooled for audit or later reuse. The PR 2 completion
transaction remains the only authority that applies the parent action and
approved selection movement.

Selective clip revision must distinguish the old active selection from a clip
already produced by the exact same child run. The former must not suppress an
approved revision; the latter is the durable crash/retry result and must be
reused to avoid a duplicate provider call and charge.
