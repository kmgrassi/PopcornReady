## Lesson

Stable-target helpers are not a safety boundary until the engine invokes them
before the first durable or provider side effect. A parse-once preparation seam
keeps model validation, trusted scope, action params, cost estimation, and tool
execution from drifting.

A finite-run session claim fences provider work, but it does not authorize a
late active-selection write. Claimed domain media should stay pooled unless an
explicit transactional selection operation owns compare-and-swap semantics.
In-session prerequisite recovery can safely rejoin pooled outputs through
immutable creation-action attribution to the exact run plus stable beat or
anchor identity.
