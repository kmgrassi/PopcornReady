## What helped

The production run exposed both the raw object-store message and the exact
stage where generation stopped. Following the persisted storyboard asset into
the keyframe request made it possible to distinguish a pre-provider reference
download failure from an image-provider failure. Independent research then
confirmed that writes and reads were keyed off two unrelated backend flags.

## Friction and improvement

The existing storyboard/keyframe integration validates plan provenance,
selection, and tool acceptance but stops before reference bytes are resolved.
Storage-backed handoff tests should cross the object-store read boundary so a
successfully persisted asset is proven consumable by the next generation
stage. Shared byte readers should live beside the object-store implementation;
API features should not infer storage location from database configuration.
