## Goal and acceptance criteria

Create a focused series of automated database contract tests that would have
caught the production `orchestratorContext.listPanels` read of retired
`public.storyboard_panels` before deployment and that provides reusable
coverage for the project's recurring schema/permission failures.

- Static or deterministic contract coverage rejects production API references
  to explicitly retired database surfaces.
- A local-Supabase integration path exercises the production orchestrator
  context reader against the migrated schema without provider calls.
- Authorization coverage distinguishes user-scoped RLS, service-role, and
  least-privilege direct-role expectations.
- The suite produces actionable failure messages and is documented with exact
  commands.
- No retired schema is restored and no provider-backed generation is invoked.

## Decisions

- Fix all four stale reader methods in this PR. A green test that avoids the
  production reader, or a required test knowingly left red, would provide false
  confidence.
- Keep direct `popcorn_api` coverage operation-specific; do not broaden that
  least-privilege role to the story spine merely to create a universal rights
  test.
- Keep provider-backed generation outside the suite. Loading context and
  querying RLS rows deterministically proves the pre-tool failure boundary
  without spending credits.

## Blockers and risks

- A broad source scan can produce false positives from migrations, tests, and
  historical documentation; scope it to production runtime code and keep the
  retired-surface catalog explicit.
- Service-role success does not prove request-RLS access, while request-RLS
  denial does not imply a missing schema object. Test these boundaries
  separately.
- Local integration must not invoke model or media providers.
- Docker/local Supabase is currently unresponsive in this environment, so the
  real schema/RLS test remains the one unexecuted validation checkpoint.
- A hosted schema-cache smoke remains intentionally unimplemented until an
  approved production test project/session is available; it must be read-only
  and cannot substitute for the local RLS matrix.
