## Goal

Remove the unchecked `as NvidiaCosmosResponse` cast at the NVIDIA provider
boundary and make malformed successful responses fail with a controlled error.

## Research

- Read `AGENT_WORKFLOW.md`, `CLAUDE.md`, and `docs/repository-structure.md`.
- The repository uses strict TypeScript, but `JSON.parse` is still an external
  runtime boundary and the NVIDIA provider asserted its shape without checking.
- Existing provider tests cover the valid `b64_video` path but not malformed
  success payloads.
- Independent review is unavailable unless `AGENT_REVIEW_COMMAND` is configured.

## Plan

1. Add a runtime guard for the optional NVIDIA response fields.
2. Remove the unchecked response cast and add a malformed-payload regression test.
3. Run focused tests, typechecks, lint, and agent validation.

## Changes

- Added `isNvidiaCosmosResponse` to validate provider JSON before use.
- Removed the unchecked response assertion.
- Added coverage for a 200 response whose `b64_video` field has the wrong type.
