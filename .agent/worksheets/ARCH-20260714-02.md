## Goal and acceptance criteria

Revise the proposed orchestration scope so it captures the agreed refinement:
the root is a creative director plus router, domain agents reuse the existing
durable `driveLoop`, Visuals owns the still-to-motion chain, and domain sessions
persist per project.

Acceptance criteria:

- Root and domain responsibilities match the refined architecture.
- The scope explains precisely what reusing `driveLoop` does and does not mean.
- Tool ownership covers every current primitive tool.
- Domain tasks/reports are typed and communication occurs only at turn boundaries.
- Persistent sessions are distinct from finite assignment runs.
- Asset-graph state, provenance, concurrency, compaction, costs, approval,
  cancellation, recovery, feedback, UI, rollout, and cleanup are covered.
- The roadmap includes an early decision-eval adoption gate.
- The update is validated, independently reviewed, and published to the existing

## Decisions

- The root is the creative director and router, never a router alone.
- Root retains brief/story/script/shot/visual-anchor planning,
  `assemble_timeline`, `critique_timeline`, `request_approval`, `export_video`,
  and completion.
- The first domain agents are Visuals and Audio. Visuals combines image and
  video work so storyboard → keyframe → clip recovery stays in-domain.
- Every agent uses the exact existing `driveLoop` through an `AgentDefinition`;
  no second runtime or per-domain engine fork is introduced.
- One persistent session exists per project/domain, while each assignment uses a
  finite durable run linked to that session.
- Inter-agent reports are `done | blocked | question`; failures and cancellation
  remain runtime assignment states.
- The asset graph is the only canonical creative-state channel. Session memory
  stores compact control continuity, not copied project truth.
- Decision evals form an early proceed/defer gate before runtime investment.
- The revised implementation plan contains seventeen PRs, with default-on soak
  separated from destructive cleanup.
