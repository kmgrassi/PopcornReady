## Goal and acceptance criteria

Strengthen the type boundary between the web preview player and the renderer
composition. Stop casting the composition to an untyped React component, and
document the framework-required renderer prop constraint. Acceptance: the
active web and renderer typechecks pass, the preview path remains covered by
its existing build-time contract, agent validation passes, and an open PR is
created.

## Decisions

- Scope the change to `packages/renderer/src/VideoComposition.tsx` and
  `apps/web/src/components/PreviewPlayer.tsx` because the current boundary
  explicitly widens the composition props and then erases them at the call
  site.
- Keep runtime behavior unchanged; this is a compile-time contract tightening.

## Changes

- Removed the `as React.FC` cast from `apps/web/src/components/PreviewPlayer.tsx`
  so `VideoComposition`'s `VideoProps` contract reaches Remotion's `Player`.
- Kept `VideoProps extends Record<string, unknown>` because Remotion's
  `Composition` and metadata generics require that index-signature constraint,
  and documented why it remains.
