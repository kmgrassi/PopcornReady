## Decisions

The reported 404 was the assistant-provided workspace route (`/projects/:id`),
not the product's public-share route (`/p/:id`), so no share-link code change is
needed. The production failure is an async-completion race: a storyboard worker
can resume an active run before its accepted invocation is recorded and parked.

## Changes

The engine now reconciles terminal async jobs immediately after parking. Async
tool workers now wake the durable dispatch queue rather than calling the engine;
the leased recovery worker is the sole production owner of a model turn. The
recovery worker drives orphaned active runs through the regular entrypoint and
resumes only parked runs. Both paths reconcile any durable in-flight job before
another model turn. Regression coverage proves a completed storyboard action
precedes keyframe execution, including after a claimed-resume crash. The wake
RPC preserves an existing dispatch lease, so a fast completion cannot requeue a
run an active worker still owns.
