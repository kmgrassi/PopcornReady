## Decisions

- PR 7 owns isolated `orchestrator-context/` modules. It does not edit the
  PR 5/6 store/lifecycle files, which are intentionally sequential owners.
- Target guards are pure, fail-closed server-side functions. PR 5/6 can call
  them immediately before selection, edge, and asset writes in their transaction.
- Model-facing projections separate trusted control fields from creator/project
  content and never carry provider responses, raw action histories, or tools.
