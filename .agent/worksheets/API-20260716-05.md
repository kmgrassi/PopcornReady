## Goal and acceptance criteria

Record production text-model usage and estimated cost in `model_call_costs` so
operator investigation can see LLM reasoning alongside media generation.

- OpenAI and Anthropic adapters retain provider usage for every returned response.
- Live API call paths can record token usage with project/run attribution.
- Orchestrator model-decision calls are ledgered as agent reasoning glue (no
  action id) and associated with the durable run.
- Provider cache-token buckets contribute to an estimated, versioned rate
  calculation instead of being silently counted as ordinary input tokens.
- Targeted unit tests prove response usage, retry accounting, pricing, and
  concurrent attribution isolation.
- Documentation, feedback record, validation, independent reviews, commit, tag,
  and an open PR accompany the code change.

## Decisions

- Preserve usage at the two adapter boundaries with an async-local observer,
  rather than adding mutable state to cached clients or embedding persistence in
  the shared package.
- Price the configured OpenAI GPT-5/GPT-5 mini and Anthropic Opus/Haiku models
  using current standard API rates. Ledger rows remain `is_estimate: true`;
  unrecognized model overrides write a zero-dollar row and a warning instead of
  applying an incorrect rate.
- Attribute root decisions to project plus durable run, and direct/tool calls to
  their known project/run/action. Do not invent ownership for global naming,
  embeddings, or review paths without a project ID.
- This change is post-hoc provider-cost visibility only. It does not reserve a
  text-model budget before a request or settle credits after one.

## Changes
