## Decisions

- Use one root project orchestrator plus six specialists: story, image, video,
  audio, edit, and review.
- Stop the hierarchy at two agent levels; specialists return handoffs to the
  root instead of delegating.
- Preserve the existing primitive tools, actions, asset graph, selections,
  jobs, dispatch queue, and deterministic renderer.
- Keep export as deterministic root-level execution rather than an export agent.
- Treat approval, child wait/resume, retry, budget, and cancellation as engine
  control-plane behavior rather than model-facing craft tools.
- Model specialists as durable child `orchestrator_runs`, not in-memory calls.
- Require idempotent action recording before child-run work.
- Split implementation into 19 PRs, with six specialist PRs parallelizable
  after shared runtime work.
