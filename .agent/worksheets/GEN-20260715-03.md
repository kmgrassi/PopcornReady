## Goal and acceptance criteria

Fix the production 10-second generation path that ended with a storyboard and
no playable video.

- Prompt and uploaded-footage generation run end to end by default; partial
  stop-after behavior is opt-in.
- `generate_keyframe` resolves the storyboard tied to the active plan even when
  the project's current story-blueprint pointer changes.
- A storyboard/keyframe handoff is valid only when every planned beat has a
  selected persisted storyboard tile.
- The storyboard worker fails rather than publishing an incomplete handoff.
- Targeted API tests, the affected application path, and repository validation
  pass before an open PR is created.

## Production evidence

- Production project: `befaf6fa-bebd-42bb-8e05-aa80a0b9ba3c`.
- Production run: `aae2708b-f052-47c3-a990-d3d8bcc61d74`.
- The 10-second run stopped after 4:27 with `Storyboard ready; no video was
  created.`
- The stage rail preserved a recoverable `generate_keyframe` prerequisite
  failure and showed keyframes/clips as failed.
- The New Project UI promised an automatic rough cut, but its request omitted
  `runThrough`; the API interpreted omission as `stopAfter=storyboard`.

## Research and decisions

- Independent research found the storyboard/keyframe handoff reads only
  `projects.current_story_blueprint_id`, a pointer also owned by story
  development. The keyframe contract must instead resolve by the active plan
  asset id.
- Independent UI review found a reached stop-after gate can make the terminal
  surface look like a successful 100% generation even though the requested
  product outcome was a video. Removing the implicit gate fixes the production
  path; explicit checkpoint behavior remains supported.
- Independent test review found no real coverage for incomplete/unselected
  panels or a storyboard worker reporting success with too few panels.
- Plan review kept explicit `runThrough: false` as an opt-in storyboard stop,
  required exact expected/persisted beat-id equality, and required plan lookup
  to skip partial newer storyboard attempts in favor of a complete usable one.
