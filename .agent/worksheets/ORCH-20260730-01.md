## Goal and acceptance criteria

Fix the production creator-direct run failure at
`orchestratorContext.listPanels` by moving the graph snapshot reader from the
retired legacy storyboard table family to the unified relational story spine.

- Authorization remains the first read before any project content.
- Story blueprint, scene, beat, and panel rows retain project scoping.
- Existing snapshot and target-scope contracts receive correctly mapped unified
  story-spine rows.
- A production-shaped regression test invokes the real reader methods and fails
  if a retired table name returns.
- The affected API/orchestrator path runs locally, and the production failure is
  re-smoked after merge.
