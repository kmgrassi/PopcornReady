## Goal and acceptance criteria

Make active story blueprint and matching script content inform `plan_shots` and make that dependency durable in the asset graph, without requiring either for visual-first videos.

## Context and source-of-truth documents

`AGENTS.md`, `AGENT_WORKFLOW.md`, `CLAUDE.md`, `docs/repository-structure.md`, `docs/NORTH_STAR.md`, and `docs/scopes/story-spine-unification.md`.

## Decisions

Use a narrow bridge rather than the draft schema-unification migration. A blueprint is optional; a script is used only if it belongs to the active blueprint.

## Changes

- `plan_shots` now loads the active blueprint and its matching script, supplies a compact narrative context to `planEdit`, and leaves both optional.
- Plan persistence records the narrative assets as provenance inputs, so later graph invalidation can see the dependency.
- Narrative lookup falls back to the newest asset-backed blueprint when the shared project pointer names an assetless storyboard container.
- Targeted tests cover matching-context use, stale-script exclusion, and existing script-free behavior.
- Updated the story-spine scope to describe this bridge and its remaining limitation.
